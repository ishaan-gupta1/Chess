# Chess
Chess app made in C++, decided to thug it all in one .cpp file, uses FEN to create boards.

Coded in Microsoft Visual Studio 2026.

Dimensions are made in mind for my 1440p monitor, currently won't fit all screen sizes.

Pass and play, or play against simple bot.

Currently has essentially all normal chess features, check, checkmate, en passant, castling, and can move back and forth between moves. Has 10:00 timer.

Click pieces to move.
Press 'R' to restart.
Use arrow keys to move back in forth in moves.
