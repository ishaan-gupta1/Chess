# Chess
Chess app made in C++ using raylib, decided to thug it all in one .cpp file, uses FEN to create boards.

Coded in Microsoft Visual Studio 2026.

Dimensions are made in mind for my 1440p monitor, however dimensions can be changed at top of file and I have tried to make 
positioning and scaling more dynamic based on resolution, however not all yet is dynamic.

Pass and play, or play against simple bot.

Currently has essentially all normal chess features, check, checkmate, en passant, castling, and can move back and forth between moves. 
Has 10:00 timer on pass and play mode.

Click pieces to move.

Press 'R' to restart.

Use left and right arrow keys to move back in forth in moves.

Use Enter and up and down arrow keys to navigate the menu.

Press 'Q' to go back to menu.
